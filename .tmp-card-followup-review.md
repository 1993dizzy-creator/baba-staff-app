## Migration changes

- Removed only the new CARD_LEGACY_UNALLOCATED preflight check. Existing month-scoped CARD_UNMATCHED unchanged. Deposit-auto-allocation's conservative later unmatched/partial safety check retained.
- Added private, RLS-enabled/revoked cancellation_permissions and exact allowed_reversal authorization. Public cancellation RPC retains its grants and legacy implementation, routing only automatic post-close fees to the narrow path.
- Actor/reason/current business month checks remain. Closed legacy fees remain blocked.
- Reversal: actual cancellation business date/time, original fee recognition_month, economic_effect_sign=-1, correction_of_id=original. One positive clearing movement, no bank movement. Original transaction and fee allocation lines untouched.
- Only matching confirmed -> cancelled closure metadata update is authorized. Audit and capability deletion are atomic; failure rolls back everything.
- No reopen or closure snapshot rewrite.

## Snapshot code locations

- lib/ledger/month-close.ts: buildMonthCloseSnapshot uses recognition_month for profit and business_date cutoff for funds. This implementation is unchanged in this follow-up.
