## 변경

- 미지급 확정 입고의 자동 재기표 범위: 당일 → 현재 영업월(`store_business_date_for_timestamp_v1`, 03:00 기준).
  이전 달 입고는 기존처럼 관리자 검토, 월마감·지급·배분·수기금액 보호는 그대로.
- 지급완료 입고 실청구금액 **감액만**: 원 비용 전표·후불·배분·지급 전표/이동 보존.
  감소액 = 비용 정정 전표(`inventory_purchase_billed_correction`, expense, sign −1, 지급일·지급계정) + 지급계정 +이동 + 감사.
  원천 후보 스냅샷을 새 금액으로 갱신하고 같은 트랜잭션에서 기존 프로젝터가 `UNCHANGED/METADATA_SYNCED`여야 커밋.
  재시도는 `no_change`, 정정 전표는 `(source_type, source_key)` 유일 인덱스로 1회.
- 대상 외(증액, 수량·단가·거래처 변경, 분할 배분, 카드 지급, 이전 달 지급, 마감월, 수기 장부금액)는 기존 `payment_completed` 차단.
- `/inventory/snapshots`: 서버가 준 현재 영업일의 같은 월 입고만 수정 버튼 표시.
