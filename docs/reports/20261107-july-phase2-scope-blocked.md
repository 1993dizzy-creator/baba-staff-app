## 판정에 남은 근거

확정 80행의 원본 행번호와 각 행에 귀속하는 원입고 ID 목록, 기존 보류 6행 목록이 필요하다. 로컬 추가 명세 파일 경로만 있어도 된다. 메모에는 다음과 같이 포함·제외·정정 ID가 함께 등장하므로 모든 `#번호`를 구매 연결로 취급할 수 없다.

- 시트 53행은 #5914·#5915·#5916에 연결하며, 메모에 함께 적힌 #5912·#5913은 각각 54·55행 소속이다.
- 시트 81행의 #6217은 재기록 여부 미확정 예외이며, #6212·#6213·#6214와 함께 지급 대상으로 합산하면 안 된다.
- 시트 111행은 양수 입고뿐 아니라 음수 정정 #6421을 보존해야 한다.
- 시트 21행은 품목명 불일치, 214행은 날짜·품목 설명 불일치, 398행은 공급자·차액 사유가 약한 후보다. 이 예시들을 사용자가 말한 정확한 6행 목록으로 간주하지 않았다.

사용자가 제공한 최신 운영 조회 결과(49건 confirmed/audit, 구매 양수 710건, billed/supplier NULL, 직접 연결 전표·후보 0건, 카드정산 69건, Carlsberg 지급 완료, 계정 active_from)는 참고 증거로 보존한다. 이번에 새로 조회하거나 관측한 결과는 아니다. NULL 청구액 및 0건 후보만으로 모든 지급·후불의 중복 위험이 해소됐다고 판단하지 않는다.

명세 확정 후에는 해당 ID의 현재 입고·전표·후불·배분만 좁혀 읽기 확인하고, 세 그룹을 확정한 뒤 등록 가능한 행만 별도 승인 플레이스홀더가 있는 원자적·멱등 SQL로 작성한다. 기존 49행의 고정 번들/검산 가드는 완화하지 않는다. 원입고 수정 및 기존 지급배분 수정 없이 연결할 수 있는 경로가 확인돼야 한다. 기존 repair RPC 중 원입고 로그를 갱신하는 경로는 이번 배치에 사용하지 않는다.
